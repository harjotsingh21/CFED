# CFED

<a target="_blank" href="https://cookiecutter-data-science.drivendata.org/">

This is a Python package to estimate the Average Temperature Response over 100 years (ATR100) per unit fuel or kilometers traversed for different aviation-related climate forcers, i.e. CO2, H2O, NOx, and Contrail-induced cirrus (CiC). The function is designed to be suitable for integration in the aircraft engine design framework.
